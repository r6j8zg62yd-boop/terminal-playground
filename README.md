# Terminal Playground

A full multi-language sandbox for experimenting with code, shell commands, tooling, and examples from multiple ecosystems in one place.

## Contents

- `bash/` — shell scripts and terminal utilities
- `node/` — JavaScript/TypeScript examples
- `python/` — Python samples and tooling
- `go/` — Go examples
- `sql/` — SQL playground scripts
- `docs/` — project guidance and reference notes
- `scripts/` — automation and workspace utilities
- `README.md` — project overview

## Quick Start

### Bash
```bash
bash bash/hello.sh
```

### Node
```bash
node node/hello.js
```

### Python
```bash
python3 python/hello.py
```

### Go
```bash
go run go/main.go
```
