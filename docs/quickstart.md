# Quickstart

This repository is a full multi-language terminal playground for experimenting with common code and shell workflows.

## Prerequisites

- Bash
- Node.js
- Python 3
- Go
- SQLite or another SQL client

## Commands

### Bash
```bash
bash bash/hello.sh
```

### Node
```bash
node node/hello.js
```

### Python
```bash
python3 python/hello.py
```

### Go
```bash
go run go/main.go
```

### SQL
```bash
sqlite3 sql/demo.db < sql/setup.sql
```
